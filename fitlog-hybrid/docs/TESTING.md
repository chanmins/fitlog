# 테스트

> **시뮬레이터/에뮬레이터만으로는 이 앱을 검증할 수 없습니다.** 백그라운드
> 정책, 절전 모드, 알림 타이밍은 실기기에서만 진짜입니다. 최소한 아이폰 1대,
> 안드로이드 1대에서 아래를 다 통과시키고 제출하세요.

기록용 표는 맨 아래에 있습니다.

## A. 기본 동작 (양쪽 플랫폼)

**A1. 앱이 뜬다**
앱 실행 → 홈 화면이 뜨고 기존 기록이 그대로 보인다.
*Android 에서 기록이 비어 보이면 출처가 어긋난 것입니다 — `Config.APP_HOST`
확인.*

**A2. 로그인**
로그아웃 → 아이디/비밀번호로 로그인 → 기록이 돌아온다.
구글 로그인도 눌러 봅니다 (막히면 `DEVELOPMENT.md` 의 "구글 로그인" 절).

**A3. 기록·동기화**
세트를 하나 추가 → 웹(브라우저)에서 같은 계정으로 열어 그 세트가 보인다.

## B. 휴식 타이머 — 이 앱의 존재 이유

**B1. 포그라운드**
세트 체크 → 화면 아래 휴식 바가 뜨고 1초씩 줄어든다 → 0 이 되면 소리와
진동이 난다. **알림 배너는 뜨지 않아야 합니다** (보고 있는 화면 위에 같은
말이 겹치면 안 되므로 일부러 숨깁니다).

**B2. 백그라운드 ★ 핵심**
휴식 시작 → 홈 버튼으로 나가기 → 다른 앱(카톡 등) 사용 → 설정한 시간에
알림이 온다 → 누르면 앱이 열리고 휴식 바가 "완료" 상태다.

**B3. 화면 꺼짐 ★ 핵심**
휴식 시작 → 전원 버튼으로 화면 끄기 → 잠금화면에 알림이 뜨고 소리가 난다.

**B4. 앱 완전 종료 ★ 핵심**
휴식 시작 → 앱을 최근 목록에서 밀어 종료 → 시간이 되면 알림이 온다.
*여기가 PWA 와 갈리는 지점입니다. 실패하면 예약이 안 걸린 것입니다.*

**B5. ±15초**
휴식 중 `+15` 를 세 번 누른다 → 화면의 남은 시간과 **실제 알림 시각이
일치**한다. (스톱워치로 재세요. 예약을 다시 안 걸면 화면만 늘어나고 알림은
원래 시각에 옵니다.)

**B6. 취소**
휴식 중 X 를 누른다 → 바가 사라지고, 원래 끝날 시각이 지나도 **알림이 오지
않는다**.

**B7. 알림에서 끄기 (Android)**
휴식 시작 → 알림창의 "휴식 끝내기" → 앱으로 돌아오면 휴식 바가 이미 없다.

**B8. 되살리기**
휴식 시작 → 앱 완전 종료 → 20초 뒤 다시 실행 → **남은 시간이 이어서** 보인다
(처음부터 다시 세면 안 됩니다).

**B9. 정확도**
90초 휴식을 스톱워치와 나란히 재본다. 오차 ±2초 이내.

**B10. 연속 세트**
세트를 5개 연속으로 체크한다 → 매번 새 휴식이 시작되고, 이전 알림이 남아
쌓이지 않는다.

## C. 오프라인

**C1. Android — 첫 실행부터 오프라인**
앱 데이터 삭제 → 비행기 모드 → 실행 → **화면이 뜬다**
(APK 안의 파일로 띄우므로 됩니다).

**C2. iOS — 두 번째부터 오프라인**
온라인으로 한 번 실행 → 비행기 모드 → 재실행 → 화면이 뜬다
(서비스워커 캐시). *첫 실행부터 오프라인이면 재시도 화면이 나오는 것이
정상입니다.*

**C3. 오프라인 타이머**
비행기 모드에서 휴식 시작 → 앱 나가기 → 알림이 온다.
*타이머는 네트워크와 아무 상관이 없어야 합니다.*

**C4. 네트워크 복귀**
비행기 모드에서 세트 기록 → 비행기 모드 해제 → 잠시 뒤 웹에서 그 기록이
보인다.

## D. 껍데기 기능

**D1. 뒤로 가기 (Android)**
탭을 몇 번 이동한 뒤 뒤로 가기 → 웹 화면이 뒤로 간다. 더 갈 곳이 없으면
앱이 닫힌다.

**D2. 백업 내보내기**
설정 → 내보내기 → 공유 시트가 뜨고 JSON 파일이 저장된다.
*blob 다운로드는 웹뷰가 기본으로 처리하지 못해 따로 구현한 부분이라 꼭
확인하세요.*

**D3. 백업 가져오기**
설정 → 가져오기 → 파일 선택창이 뜨고, 방금 내보낸 파일을 고르면 복원된다.
**취소했다가 다시 눌러도 창이 다시 뜬다** (한 번 취소하면 잠기는 버그가
흔합니다).

**D4. 외부 링크**
개인정보처리방침 같은 외부 링크 → 앱 안이 아니라 사파리/크롬에서 열린다.

**D5. 키보드**
운동 이름 검색이나 메모 입력 → 키보드가 올라와도 입력창이 가려지지 않는다.

**D6. 회전·다크모드**
기기를 돌려도 세로 고정. 시스템을 밝은 테마로 바꿔도 앱은 어둡게 유지.

## E. 성능·안정성

**E1. 메모리**
Android Profiler / Xcode Instruments 로 10분 사용 → 메모리가 계속 우상향하지
않는다.

**E2. 배터리**
휴식 타이머를 20회 돌린 뒤 배터리 사용량 확인. 이 설계는 타이머 중에 우리
코드가 깨어나지 않으므로 거의 0 이어야 합니다. 눈에 띄게 소모된다면 어딘가
반복 실행이 남아 있는 것입니다.

**E3. 제조사 절전 (Android)**
삼성·샤오미 기기라면: 배터리 최적화를 **켠 채로** B4 를 다시 해 봅니다.
밀린다면 설정 안내 문구를 앱에 넣는 것을 고려하세요.

**E4. 첫 로딩**
앱 아이콘 탭 → 화면이 보이기까지 3초 이내 (Android 는 1초 이내여야 정상).
