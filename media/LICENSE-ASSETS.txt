· SVG 의 width / height 속성을 제거해 화면 크기에 맞게 늘어나도록 함
· 한 운동의 3장이 같은 화면 좌표를 쓰도록 viewBox 를 세 장의 내용
  경계를 합친 값으로 통일 (그림 자체는 고치지 않음)
· 파일 이름을 {운동id}-{프레임번호}.svg 로 변경
